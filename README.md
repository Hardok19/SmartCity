# SmartCity
Diseña e implementa una arquitectura integral de gestión y análisis de datos urbanos basada en:
• PostgreSQL
• MongoDB
• Apache Hadoop
• Apache Spark
que permite almacenar, procesar y analizar grandes volúmenes de datos provenientes de sensores IoT y
sistemas urbanos inteligentes, facilitando la generación de conocimiento para la toma de decisiones
mediante consultas y procesos de análisis las capacidades, diferencias y dominios de aplicación de cada
tecnología.
